# a page template (as {{name}}).  The browser checks each file against its hash and refuses one that
# has changed, so to use another version, change its address and its hash together.
# (The pages may load scripts and styles only from unpkg.com, and tiles from tile.openstreetmap.org:
# that is fixed in the server, see serve/handler.nim.)
